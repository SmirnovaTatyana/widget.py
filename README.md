# Bank Operations Widget

## Описание

Этот проект представляет собой виджет для отображения банковских операций клиента.
Он предоставляет функции для фильтрации и сортировки данных об операциях.

**Дополнение к описанию (Новые функции и возможности):**

*   **Работа с JSON-файлом:** Теперь проект умеет читать данные о банковских операциях из JSON-файла (`operations.json`), расположенного в директории `data/`. Реализована функция, которая обрабатывает случаи, когда файл не найден, пустой или содержит некорректные данные (не-список), возвращая пустой список.

*   **Конвертация валют:** Добавлена функция конвертации валют из USD и EUR в рубли.  Для получения актуального курса валют используется внешний API (Exchange Rates Data API). Ключ для доступа к API хранится в файле `.env` (необходимо создать его в корне проекта).

# Модуль `generators`

Модуль предоставляет инструменты для работы с большими объемами данных транзакций через генераторы.

## Функции

- **`filter_by_currency(transactions, currency_code)`**
  Фильтрует транзакции по заданной валюте.

- **`transaction_descriptions(transactions)`**
  Возвращает описания транзакций.

- **`card_number_generator(start, stop)`**
  Генерирует номера банковских карт в формате `XXXX XXXX XXXX XXXX`.
## Декоратор `log`

Декоратор `log` автоматически регистрирует детали выполнения функций:
- Время вызова.
- Имя функции.
- Передаваемые аргументы.
- Результат выполнения или сообщение об ошибке.

### Пример использования
from decorators import log


@log(filename="mylog.txt")
def my_function(x, y):
    return x + y


my_function(1, 2)
