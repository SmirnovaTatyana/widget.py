# Bank Operations Widget

## Описание

Этот проект представляет собой виджет для отображения банковских операций клиента.
Он предоставляет функции для фильтрации и сортировки данных об операциях.

# Модуль `generators`

Модуль предоставляет инструменты для работы с большими объемами данных транзакций через генераторы.

## Функции

- **`filter_by_currency(transactions, currency_code)`**
  Фильтрует транзакции по заданной валюте.

- **`transaction_descriptions(transactions)`**
  Возвращает описания транзакций.

- **`card_number_generator(start, stop)`**
  Генерирует номера банковских карт в формате `XXXX XXXX XXXX XXXX`.
